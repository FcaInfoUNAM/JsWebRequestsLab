1. ¿Qué es el objeto generado por XMLHttpRequest?
Proporciona una interfaz para realizar solicitudes HTTP desde el cliente hacia el servidor.

2. ¿Qué hace el método open de xhr?

3. ¿Qué hace el método onload de xhr?
Es un evento que se activa cuando la solicitud HTTP se completa satisfactoriamente.
